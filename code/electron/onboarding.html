feather

To get started, you'll need to create your own Google API credentials. This keeps your email data private — only you can access it. One-time setup, about 5 minutes.

Setup

1 Go to the Google Cloud Console and create a new project (e.g. "feather").

2 Enable these APIs: Gmail, Calendar, Docs, Drive.

3 Go to OAuth consent screen → pick External → fill in app name, your email for support and developer contact. Add yourself as a Test user. Save.

4 Go to Credentials → Create Credentials → OAuth client ID → Application type: Web application. Under Authorized redirect URIs, add:

http://localhost:3100/api/auth/callback/google

5 Copy the Client ID and Client Secret and paste them below.

Your credentials

These are stored only on this Mac, in your user library folder. They never leave your computer.
